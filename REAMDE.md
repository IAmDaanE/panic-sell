# Panic Sell

Analyse the stock market and trade your way to millions.

## About the Project

This was my first big project (explains why the codebase is a disaster). It doesn't use real world prices but I made a stock market simulation with crashes and booms across the stocks and bubble phases to anticipate a crash.  


---


The game is sort of turn based, each day you get a chance to sell or buy stocks of a company and then press a button to advance a day or 10 days, each day a new candle is generated.

## Project Status

It works but the stock market simulation system could definitily use some work, feel free to try and improve it, it's an interesting project.

## Getting Started

### Getting the Source

This project is [hosted on GitHub](https://github.com/IAmDaanE/panic-sell). You can download the zip or clone this project directly using this command:

```
git clone git@github.com:IAmDaanE/panic-sell.git
```

### Running the Program

Requirements: You must have Python 3.6 - 3.11.
1. Clone the repository or download the zip and unpack it to your directory of choice.
2. Navigate to that directory in a terminal.
3. In a venv or the global python version install the needed libraries.
    ```
    pip install -r requirements.txt
    ```
4. Run the program.
    ```
    python panic_sell.py
    ```
